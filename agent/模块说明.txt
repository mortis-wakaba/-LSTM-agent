agent 模块详细分工说明

本项目 agent 文件夹下包含三个核心代码文件，它们共同构建了一个基于大语言模型Agent和LSTM量化模型相融合的智能股票定价推理与决策系统。以下是各个文件的详细功能说明：

1. reasoning.py (核心推理引擎)
该文件实现了名为 FinancialAgent 的金融推理实体类，是系统针对突发事件进行逻辑传导的大脑。主要功能包括：
- 冲击传导计算 (propagate_impact)：当市场发生突发新闻时（如针对某支股票的利好/利空），基于广度优先搜索 (BFS) 算法，在产业链网络图谱中进行事件的多跳级联传播。它根据节点间的关系类型权重（正相关合作衍生或竞争互斥）以及衰减系数，计算事件冲击力向上下游甚至竞品的波及情况。
- 资产记忆与衰减 (daily_decay)：模拟市场对新闻影响的“遗忘曲线”。依靠内部字典维护股票打分状态池，实施每日折扣衰减；并能智能区分：针对剧烈波动的“重大事件”衰减较慢，常规事件则常规化快速衰减。
- 主观特征提取 (get_feature_vectors)：对外输出目标股票的主观特征向量（综合打分与重大事件标识），作为后续网络双轨融合的重要输入源。
*注：该引擎遵循控制反转设计，解耦了对图谱的直接获取，易于与真实的图谱接口对接。*

2. dynamic_gating.py (动态门控融合模块)
该文件实现了名为 FusionEngine 的决策机制类，担当最终买卖量化指令下发的中枢。它的核心作用是将基于深层量价的 LSTM 预测特征与突发逻辑驱动的 Agent 即时分数进行动态权重分配和融合。包含两种机制：
- 模式 A (数学门控驱动)：基于数学公式的动态赋权。通过引入超参数控制非线性放大，且在遭遇“核弹级事件/长假断档接管”时，强制赋予 Agent 端更高的权重下限，弥补传统量价模型滞后的缺陷。
- 模式 B (双向注意力适配)：模拟论文级的交叉注意力（Cross-Attention）对齐。通过提取 LSTM 特征内部弥散度计算模拟的注意力分数 (Softmax归一化)，在模型不确定性越高或突发事件越剧烈时，“智能”调高 Agent 推理的权重。
- 离散化映射：最终将融合所得的连续得分映射为 "STRONG BUY", "BUY", "HOLD", "SELL", "STRONG SELL" 五挡实操交易信号。

3. mock_interfaces.py (模拟外部依赖接口)
该模块按照“接口先行”和独立解耦原则，模拟了假设中同组队友负责的“图谱数据层”和“LSTM模型层”真实环境，保障了现有 Agent 逻辑可以被完整跑通：
- BaseGraphProvider：构建抽象图谱基类以规范后续真实图谱的数据调用。
- MockTeammateA (模拟图谱和新闻数据)：程序化随机生成了50只算力股（如“天孚通信”、“中际旭创”）的大型关系网络图谱（涵盖供应链正相关、竞争竞对负相关等）；同时提供 `get_latest_news` 方法，模拟经大模型提炼后的突发利好/利空新闻事件与冲击分数。
- MockTeammateC (模拟深度学习模型端)：充当伪造的 LSTM 模型层，定点下发 64 维深层隐状态特征向量，为 FusionEngine 特征融合提供模拟的“历史量价预测分”和“模糊内部特征集合”。
